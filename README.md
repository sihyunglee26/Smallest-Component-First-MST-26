## Smallest-Component-First-MST-26
This repository provides sample code for the smallest-component-first (SCF) algorithm, designed for computing a minimum spanning tree (MST) on dense graphs. It also includes example outputs for reproducibility.

### Files
|     File Name       |     Description                               |
| ------------------- | --------------------------------------------- |
| [smallest_component_first.cpp](https://github.com/sihyunglee26/Smallest-Component-First-MST-26/blob/main/smallest_component_first.cpp) | Demonstrates the SCF algorithm alongside three representative MST algorithms. |
| [smallest_component_first.log](https://github.com/sihyunglee26/Smallest-Component-First-MST-26/blob/main/smallest_component_first.log) | Sample log file generated by `smallest_component_first.cpp`. |

### Requirements

- C++ compiler (e.g., g++ with -O3)

### Usage

Compile and run:

```bash
g++ -O3 smallest_component_first.cpp -o scf
./scf
```
